# Accion Trust Reporting Demo

Vue3 CDN + SFC + UnoCSS reporting cockpit for Trust Layer for Inclusive Fintech.

## Run

```powershell
node scripts\static_server.mjs 5178
```

Open http://127.0.0.1:5178/

The app loads `data/trust_report.json`, generated by the V trust engine in
`C:\git\v_projects\accion_trust_by_design_fintech`.
